# Correction connexion locale et recherche

Modifications appliquées sans changer la structure principale du site :

1. Suppression de l’alerte affichée en connexion locale :
   « Mode local hors ligne activé. Certaines fonctions serveur peuvent être indisponibles. »
   Le mode local reste fonctionnel, seul le message intrusif est retiré.

2. Correction de la recherche matière/sujet :
   - quand on clique sur un résultat de recherche, la liste se ferme immédiatement ;
   - la liste ne se réaffiche pas automatiquement pendant le changement de matière/sujet ;
   - clic hors de la zone de recherche ou touche Échap masque les résultats.
