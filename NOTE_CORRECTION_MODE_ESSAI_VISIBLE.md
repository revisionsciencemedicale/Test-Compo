# Correction mode essai gratuit

Cette version modifie le mode « Essai gratuit » afin que le visiteur voie l'aperçu général du site :

- tous les niveaux ;
- toutes les matières disponibles ;
- tous les sujets disponibles selon la matière choisie ;
- le bouton du dictionnaire médical.

Le visiteur en mode essai ne peut cependant démarrer que le quiz affecté à l'essai gratuit.

S'il essaie d'ouvrir le dictionnaire médical ou de démarrer un sujet autre que le sujet d'essai, le message suivant s'affiche :

« Veuillez disposer d’un compte personnel pour accéder à tous les quiz ainsi qu’aux corrections expliquées. Merci de contacter les administrateurs au +225 0708190886 / +225 0709282169 pour obtenir votre compte personnel. »
