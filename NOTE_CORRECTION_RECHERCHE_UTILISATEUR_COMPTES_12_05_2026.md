# Correction Recherche utilisateur / gestion comptes

Modifications appliquées directement :

- Dans **Paramètres généraux > Rechercher utilisateur** :
  - le bouton **Suspendre** suspend réellement le compte jusqu'à réactivation ;
  - la session active du compte suspendu est retirée ;
  - le bouton devient **Réactiver** pour remettre le compte actif.

- Le bouton **Modifier nom** permet maintenant de modifier :
  - le nom ;
  - le prénom ;
  - le numéro de téléphone ;
  - le ou les niveaux autorisés.

- Après modification du nom/prénom/téléphone/niveau, l'identifiant est automatiquement régénéré.

- Le bouton **Supprimer** supprime le compte de la liste des comptes actifs et déconnecte sa session.

- Le tableau **Nom d’utilisateur généré** affiché à côté de **Créer compte automatiquement** est rendu plus visible et lisible.
