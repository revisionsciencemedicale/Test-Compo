# Modification : bouton Essai gratuit

Cette version ajoute un bouton « Essai gratuit » sur l'écran de connexion.

Fonctionnement :
- Le visiteur peut entrer sans compte avec le bouton « Essai gratuit ».
- Il ne voit qu'un seul niveau : « Essai gratuit ».
- Il ne peut traiter qu'un seul sujet : « Sujet d’essai gratuit ».
- Ce sujet contient 5 questions avec correction expliquée.
- Si le visiteur tente d'accéder à un autre mode ou à un autre sujet, le message demandé s'affiche.
- Le message de contact administrateur a aussi été remplacé par les numéros avec l'indicatif +225.
