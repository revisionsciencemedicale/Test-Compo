# Correction du calcul de la note sur 20

La note sur 20 est maintenant calculée à partir de la valeur attribuée à chaque question :

- bonne réponse : ajoute la note de la question ;
- mauvaise réponse : retire la note de la question ;
- question non répondue : 0 point.

Exemple : pour un sujet de 5 questions, chaque question vaut 4 points. Si le score est -1, la note sur 20 est donc -4/20.

La partie correction affiche aussi la note obtenue pour chaque question.
