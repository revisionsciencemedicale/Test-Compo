# Correction interface tableau de bord - 30/05/2026

Modifications appliquées sans supprimer les identifiants et fonctions existants :

- Ajout d'une interface type tableau de bord inspirée de l'image fournie : menu latéral violet, barre supérieure, recherche globale, cartes statistiques, bannière de bienvenue et cartes de choix niveau/matière/sujet.
- Le menu latéral ne contient plus : Suivi, Mes Résultats, Historique, Favoris, Mes Notes.
- Les boutons du menu utilisent les fonctions existantes du site : Tableau de bord, Commencer un Quiz, Dictionnaire médical, Examens de fin de Formation, Tableau de bord Admin.
- Le menu se replie automatiquement dès qu'on clique hors du menu. Le bouton ☰ permet de l'ouvrir ou le fermer.
- La recherche globale affiche uniquement les matières et sujets disponibles dans le niveau actuellement autorisé/sélectionné pour l'utilisateur.
- Les options de niveau restent pilotées par la logique existante des comptes : un utilisateur non administrateur ne voit que son niveau autorisé dans Commencer un Quiz.
