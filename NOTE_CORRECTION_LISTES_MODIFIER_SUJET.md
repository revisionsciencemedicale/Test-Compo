# Correction — Listes déroulantes et modification des sujets

Modifications effectuées :

1. Dans **Paramètres administrateur > Gestion des quiz > Ajouter de nouvelles matières et de nouveaux sujets** :
   - les listes déroulantes Niveau, Matière et Sujet sont maintenant plus visibles et lisibles ;
   - les options ont un fond clair, une écriture sombre et plus épaisse.

2. Dans le bouton **Sujet** :
   - ajout du sous-bouton **Modifier un sujet** ;
   - lorsqu'on clique dessus, les questions du sujet sélectionné s'affichent ;
   - possibilité de modifier :
     - l'énoncé de la question ;
     - les choix de réponse ;
     - la bonne réponse ;
     - l'explication.

3. Sauvegarde :
   - en ligne : les modifications sont envoyées au serveur via les paramètres administrateur ;
   - en local : les modifications sont sauvegardées dans le navigateur pour faciliter les tests.

4. Les questions modifiées remplacent maintenant correctement la version d'origine grâce à leur identifiant unique.
