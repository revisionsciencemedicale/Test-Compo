# Correction Recherche utilisateur — 12/05/2026

Modifications appliquées :

1. Dans Paramètres généraux > Recherche utilisateur :
   - Le bouton Suspendre suspend réellement le compte jusqu'à réactivation.
   - La suspension déconnecte aussi les sessions actives du compte suspendu.
   - Le bouton Réactiver réactive le compte.
   - Le bouton Supprimer supprime le compte et déconnecte ses sessions.

2. Le bouton Modifier nom permet de modifier :
   - le premier nom / nom de famille ;
   - le deuxième nom / prénom ;
   - le numéro de téléphone ;
   - le ou les niveaux autorisés.

3. Après modification, l'identifiant est régénéré automatiquement à partir des nouvelles informations.

4. Le tableau Nom d’utilisateur généré est forcé en fond blanc avec écritures noires pour rester visible et lisible.

Fichiers modifiés : app.js, server.js, style.css.
