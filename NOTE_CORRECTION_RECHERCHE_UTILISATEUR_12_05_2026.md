# Correction — Recherche utilisateur / comptes

Modifications appliquées :

- Le bouton **Suspendre** suspend réellement le compte jusqu’à réactivation.
- La suspension force aussi la sortie de la session active de l’utilisateur.
- Le bouton **Réactiver** remet le compte en service.
- Le bouton **Modifier nom** permet maintenant de modifier :
  - le nom ;
  - le prénom ;
  - le numéro de téléphone ;
  - le ou les niveaux autorisés.
- Après modification des informations, l’identifiant est régénéré automatiquement selon les nouvelles données.
- Le bouton **Supprimer** supprime le compte de la liste active et coupe ses sessions.
- Le tableau **Nom d’utilisateur généré** est maintenant plus visible et lisible après création automatique d’un compte.
