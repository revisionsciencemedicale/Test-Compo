# Déplacement des questions EFF

Les matières et questions de l'Examen de Fin de Formation ont été regroupées dans :

`questions.examen-fin-formation.manuel.js`

Le fichier `questions.eff.js` est conservé uniquement comme fichier de sécurité pour ne pas casser le chargement existant dans `index.html`.

Pour ajouter de nouvelles questions EFF, ajoute-les dans le tableau `MANUAL_EFF_QUESTIONS` du fichier :

`questions.examen-fin-formation.manuel.js`

Niveaux à utiliser :
- `INF/SAG-M`
- `AUXI`

Les matières ajoutées manuellement, par exemple `Pathologies`, sont maintenant conservées et affichées.
