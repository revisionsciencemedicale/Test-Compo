# Correction : Prise de vue obligatoire avant quiz

Modifications appliquées :

- Le libellé `Photo obligatoire avant quiz` est remplacé par `Prise de vue obligatoire avant quiz`.
- Quand cette option est cochée, le `Mode QPQ` est automatiquement activé.
- Avant le démarrage du quiz, l'utilisateur doit autoriser la caméra et prendre une photo.
- Le quiz ne démarre pas tant que la prise de vue n'est pas validée.
- Si la caméra n'est pas disponible, un choix de photo reste disponible comme solution de secours.
- La politique serveur autorise désormais la caméra pour le site lui-même : `camera=(self)`.
