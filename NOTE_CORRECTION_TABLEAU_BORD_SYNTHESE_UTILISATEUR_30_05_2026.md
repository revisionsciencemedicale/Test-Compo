# Correction tableau de bord / synthèse / utilisateur — 30/05/2026

Modifications réalisées sans casser la structure existante :

- La page **Tableau de bord** est différenciée de **Commencer un quiz** : elle affiche une vue générale, les statistiques, la motivation et la synthèse.
- La page **Commencer un quiz** garde les sélecteurs niveau / matière / sujet et le bouton de démarrage.
- **Synthèse des questions** est maintenant un bouton : les thèmes s’affichent seulement après le clic.
- Les questions sont regroupées par vrais thèmes médicaux, sans considérer les intitulés génériques comme **Sujet 1**, **Sujet 2**, **Sujet examen**, etc.
- Ajout de regroupements comme : Paludisme, Tuberculose, VIH/SIDA, Diabète, HTA, Grossesse, Néonatologie, Fractures, Diagnostic, Signes cliniques, Définition, Prise en charge, Complications.
- Si un thème contient plus de 40 questions, il est automatiquement divisé en plusieurs groupes de 40 questions.
- Un clic sur un thème ou un groupe de thème démarre directement le quiz correspondant.
- Le badge utilisateur affiche :
  - compte créé en ligne : nom + prénom + niveau ;
  - compte local : **Étudiant(e)** + niveau.
