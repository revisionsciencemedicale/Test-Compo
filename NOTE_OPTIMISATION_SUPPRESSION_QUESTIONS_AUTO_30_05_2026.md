# Optimisation et suppression des questions automatiques

Corrections effectuées sans casser la structure du site :

- suppression des banques de questions générées automatiquement dans tous les niveaux ;
- conservation des fichiers de questions pour permettre l’ajout manuel futur ;
- conservation des questions ajoutées depuis l’administration via les paramètres locaux/serveur ;
- allègement important du chargement initial du site ;
- la synthèse des questions continue de se recalculer à partir des questions réellement disponibles.
