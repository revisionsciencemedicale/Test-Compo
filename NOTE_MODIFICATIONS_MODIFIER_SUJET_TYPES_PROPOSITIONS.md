# Modifications — Modifier un sujet

- Le contenu du sous-bouton **Modifier un sujet** s'affiche uniquement après clic.
- Le contenu se masque après l'enregistrement ou après un clic hors du bloc, tout en gardant la page principale et les sous-boutons visibles.
- Les boutons **QCM simple**, **QCM multiple** et **Vrai/Faux** changent maintenant réellement la structure de la question :
  - `mcq` pour QCM simple ;
  - `mcq_multi` pour QCM multiple ;
  - `tf` pour Vrai/Faux.
- Ajout des boutons **-** et **+** sous les propositions de réponse :
  - **+** ajoute une nouvelle proposition ;
  - **-** retire les propositions cochées.
